## Tasks

### Task 0: the shared guard, `tools/glossary.js`

It lives in tools/, like `js-source.js`, with tests in `tools/test/glossary.test.js`, and exports:
- `BANNED`, one pattern for every app:

  ```js
  /\blog(?:s|ged|ging)?[ -]?(?:in|out)\b|\blog(?:in|out)s?\b|workspace|\bpublish/i
  ```

  It must match "log in", "logs in", "logs out", "log-in", "logged in", "logging in", "logged-in", "login", "logout", "workspace" and "Publish", and must not match "catalog in" or "dialog out". The tests cover both lists.
- `proseLiterals(source)`:
  - runs `stripComments` from `tools/js-source.js`;
  - returns each `'…'`, `"…"` and `` `…` `` literal that looks like prose (contains whitespace and matches `/[A-Za-z]{3,} [a-z]/`);
  - blanks out `${…}` in template literals, since those are code;
  - runs a literal that contains `<` through `visibleText`, so attributes and class names in HTML templates don't count;
  - skips SQL: any literal containing an upper-case SQL keyword as a whole word, matched case-sensitively with `/\b(SELECT|INSERT|UPDATE|DELETE|FROM|WHERE|JOIN|VALUES|SAVEPOINT|RELEASE|CREATE|ALTER|DROP|PRAGMA|WITH)\b/`. This also covers fragments joined into a query, such as `'track WHERE workspace_id'`, and UI prose never has these words in capitals;
  - skips literals inside `console.*` calls; operator messages in `console.*` that must change are listed by file in their task.
- `openapiStrings(doc)`: every `summary`, `description` and `title` in an OpenAPI document.
- `visibleText(html)`:
  - drops comments, `<script>` and `<style>`;
  - keeps the values of `aria-label`, `title`, `placeholder` and `alt`;
  - drops the other attributes, so `value="publish"` and `href="/auth/login"` don't count.
- `exempt(text)`: removes the protocol names the decision allows (`/auth/login`, `/auth/logout`, `__Host-tinylap-login`, `?login`) before matching.

Task 0 adds only the module and its own tests. Each app's glossary test arrives in that app's task, together with the copy it guards, so every commit stays green. Allow-lists name exact strings, never patterns. The only entries expected are the accounts admin texts at `workspaces.js:314, 317`.

## Review focus

1. A string changed in source but not in the test that asserts it, or the reverse.
2. A rename that reaches an identifier, path or JSON field, breaking the API or stored data (`workspace` in API paths, `publish` values).
3. The planner drift test (`account-markup.test.js`) after the brand change.
4. The new shortcut guard swallowing a key the canvas needs. The canvas `<svg tabindex="0">` is not matched by the selector, which is correct.
5. Glossary guards that pass trivially, for example a scan that matches nothing because the extraction is wrong. Each guard needs one deliberate failing case, shown once before the fix.
